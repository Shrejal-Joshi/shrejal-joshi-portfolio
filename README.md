# Shrejal Joshi — Portfolio

A modern, responsive developer portfolio built with React, TypeScript, Vite, and CSS.

## Highlights
- Responsive, accessible single-page portfolio
- Light/dark theme toggle
- Animated hero and section reveals
- Experience, selected work, skills, and contact sections
- No backend and no UI framework dependency
- Easy to deploy on Vercel, Netlify, or GitHub Pages

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
